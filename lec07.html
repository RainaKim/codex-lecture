# 안 되는 변화: paid → pending def test_paid_to_pending_rejected(): with raises(InvalidTransition): paid_order().transition("pending")

실습 ① 결과 · 클립 1 마무리
결제 실패 주문을 지우면 무엇이 사라지나
pending 주문 · 결제 실패 발생
주문 행을 지운다
상태만 바꾼다
v0 — 실패한 주문을 삭제
✕ 감사 추적 상실 — 실패 사유가 남지 않음
✕ 멱등성 깨짐 — 재시도가 새 주문을 또 만듦
✕ 정산 불가 — 실패 건이 집계에서 빠짐
지운 뒤에는 어느 것도 코드로 되살릴 수 없다
정책 — payment_failed 로 보존
✓ 이력 보존 — 실패 사유·시각이 행에 남음
✓ 재시도 안전 — 같은 주문 ID로 다시 결제
✓ 정산 가능 — 실패 건도 관리자 조회에 잡힘
상태 하나가 이력·재시도·정산을 한 번에 지킨다
상태로 남기는 건 취향이 아니라 기술적 필연 — 삭제는 이력·멱등성·정산을 한 번에 잃는다
