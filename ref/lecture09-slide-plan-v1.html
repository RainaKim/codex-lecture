덱 성격

이 덱은 라이트 개념 덱이다. 슬라이드는 개념 앵커만 잡고 상세 설명은 스피커 노트가 맡는다. 9강 실습은 특정 Issue의 실제 계획을 쓰는 게 아니라 Lab 12에서 쓸 계획 template(구조)을 만드는 단계라서, 슬라이드에서는 「Plan」이 아니라 「Plan template」으로 부르고, 종료 조건 네 갈래(성공 / 반복 한도 / 정체 / 사람 확인)와 「사람 승인 전에는 구현으로 넘어가지 않는다」를 명시한다. 구성은 표지·리캡(01·02) → 오늘의 지도(03) → 이론 앵커 04·05 → 실습 큐 06·07·08 → 이론 앵커 09 → 실습 큐 10 → 마무리(11). 실습 큐 네 장(06·07·08·10)은 8강 큐 컴포넌트(레드 「실습」 배지 + 헤드라인)를 따르되, 각 장에 이번에 쓰는 기능 · 생각할 질문 · 확인할 것을 담아 Lab 09 E1~E4와 1:1로 붙인다. v1.3에서 실습 다섯 장(03·05·07·08·10)을 개정된 Lab 09 README에 맞춰 다시 썼다 — 실습은 「항목을 하나씩 추가」가 아니라 Codex 기능을 단계별로 쓰는 흐름이다(E1 Plan mode 설계·승인 → E2 Default mode 작성 → E3 변경사항 diff 범위 확인 → E4 Review mode 검토·최소 수정·검증). 사람 승인이 두 번(E1 설계 승인 · E4 지적 승인) 들어간다는 것이 03(오늘의 지도)에서 먼저 보인다. 8강 플랜과 같은 토큰·좌표 문법(킥커 12.18% · 헤드라인 18.8% · 스트립 79.5%)을 그대로 쓴다. 다이어그램 장(04)은 7강 05·07처럼 큰 토큰(t mid 10.5px · t 8.2px)만 쓴다.
