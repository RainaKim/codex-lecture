완료 기준이 없으면, 바로 코드로 간다
# 주문 상태 이상함 결제 실패 처리가 이상합니다. 상태를 하나 추가하고 관리자 화면에도 보이게 고쳐 주세요. 재고 문제도 같이 해결하면 좋겠습니다. 최대한 빨리 반영해 주세요.
→
현재·기대·완료 기준이 없다
범위가 계속 커진다 (재고도 같이)
구현자가 임의로 결정한다
무엇이 「됐다」인지 모른 채 Codex는 곧장 코드를 고치기 시작한다
좌: 실제 나쁜 요청(fixture) → 우: 그래서 생기는 세 결함. 완료 기준 부재가 핵심
제작 명세: 시간 배분 2.5분. 이 클립의 이론 앵커. 좌측 코드 카드에 fixture 원문(제목은 회색 u, 범위 확장·긴급은 b 강조). 우측 회색 카드 3개 = 결함(누락·범위 확장·임의 결정). 레드 없음(문제 나열). 스트립이 "그래서 바로 코드로 간다"로 못 박음.
