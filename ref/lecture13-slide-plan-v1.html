덱 성격

이 덱은 이론 + 실습 덱이다. 13강은 Chapter 3의 두 번째 강의로, 12강이 「계획과 diff를 대조해 계획에 없던 변경을 잡는다」였다면 13강은 한 겹 아래 — 계획대로 했고 파일도 맞고 설명도 그럴듯한데 부르는 것이 존재하지 않는 경우를 다룬다. 12강의 diff 대조로는 잡히지 않는다. 환각을 「토큰 예측」이나 「확률 분포」로 설명하지 않는다(앞 강의에서 이미 두 번 썼다) — 이 덱은 「모르는 자리를 비워 두지 않고, 있을 법한 걸 채운다」는 각도 하나로만 가고, 어려운 말을 쓰지 않는다. 실제 코드 예시와 실제 에러 문자열은 슬라이드에 박지 않는다 — 실습에서 나온 것을 슬라이드의 분류·구조 위에 얹는 방식이다. 구성은 표지(01) → 환각의 정체(02~07) → 실습 큐 08 → 무엇이 잡는가(09~12) → 실습 큐 13 → 복구(14) → 실습 큐 15 → 기준으로 전환(16·17) → 실습 큐 18 → 마무리(19). 07 「존재는 무엇이 증명하나」가 이 덱의 중심이다. 실습 큐 네 장(08·13·15·18)은 9강·10강 큐 컴포넌트(레드 「실습」 배지 + 헤드라인 + 위 카드 세 행 + 아래 2열)를 그대로 쓰고 네 장의 좌표를 동일하게 맞췄다(위 카드 30~46.5% · 아래 2열 50.5~78%). 클립 배분(실습 N은 클립 N에 온다): 클립 1 — 환각의 정체(약 15.5분 · 01~08) / 클립 2 — 무엇이 잡는가(약 9.5분 · 09~13) / 클립 3 — 복구(약 6분 · 14·15) / 클립 4 — 기준으로 전환(약 9.5분 · 16~19). 9강·10강 플랜과 같은 토큰·좌표 문법(킥커 12.18% · 헤드라인 18.8% · 스트립 79.5%)을 그대로 쓴다. 표 장(07·09)은 .mk table 토큰을 쓰되 헤더 배경을 인라인으로 #5B5B5B로 내려, 07의 반복 ✕(시맨틱 레드)와 장식 레드가 한 장에서 충돌하지 않게 했다.
