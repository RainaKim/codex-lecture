> **템플릿 원본 `ppt_16_9_light.pptx`는 모든 슬라이드·레이아웃·테마가 `Arial`로 지정돼 있다.** 가이드 슬라이드 3장의 "Pretendard / Gilroy"는 문서상 지침일 뿐 파일에 반영돼 있지 않다(도형 이름이 전부 `Google Shape;...` — Google Slides에서 export되며 폰트 지정이 Arial로 떨어진 것으로 추정). 폰트 임베딩도 없다.
> **따라서 템플릿에서 슬라이드를 복제한 뒤 반드시 폰트를 교체한다:**
> ```python
> # ppt/slides, ppt/slideLayouts, ppt/slideMasters, ppt/theme 전체
> s = s.replace('typeface="Arial"', 'typeface="Pretendard"')
> s = s.replace('typeface="Calibri"', 'typeface="Pretendard"')   # theme 제외
> # theme1.xml 의 <a:ea typeface="맑은 고딕"/> → Pretendard
> ```
> 렌더 검수 환경에도 Pretendard를 설치해야 미리보기가 실제와 같아진다 (`~/.fonts/` 에 OTF 복사 후 `fc-cache -f`). 설치 전 렌더는 Liberation Sans로 대체되어 **자간·줄바꿈이 실제와 다르다.**
> 임베딩은 하지 않는다 — PowerPoint 폰트 임베딩은 TrueType만 지원하고 보유분은 OTF(CFF)다. 최종 뷰어 PC에 Pretendard가 설치돼 있어야 한다.

## 6. 금지 사항

- ❌ 팔레트 외 색(파랑·초록·보라 등)
- ❌ 96px 표지형 텍스트를 본문에 사용
- ❌ 카드에 그림자·테두리 추가
- ❌ 마스터 요소(배경·로고·헤어라인) 슬라이드에 중복 배치
- ❌ 한 슬라이드에 레드 강조 2개 이상
- ❌ **블랙 반전 카드(검은 박스 + 흰 글씨)** — 강조가 필요한 진단 행은 **레드 틴트**(배경 `#FFE5EB` + 텍스트 `#FC1C49` Bold)로 한다. 덱 안에서 **다크 블록은 코드 스니펫 카드(`#1E1E1E`) 하나뿐**이어야 하며, 반전 바를 여러 장에 쓰면 코드 카드의 유일함이 사라진다
- ❌ 헤드라인 아래·슬라이드 하단의 **작은 회색 보조 한 줄**(요약·부연·다음 강 예고) — 전부 구두로
- ❌ 그라데이션 남용 (표지 배경 오브젝트 외 금지)
- ❌ 구 다크 테마 좌표계(10×5.625in) 혼용

## 7-1. 템플릿 편집 시 자주 걸리는 함정

1. **장식은 레이아웃에 있다.** 체크 아이콘, 번호 뱃지, 흰 카드 배경 등은 슬라이드가 아니라 슬라이드레이아웃의 도형이다. 5행 레이아웃을 3행으로 줄이려면 **슬라이드의 placeholder를 지우는 것만으로 부족하고 레이아웃의 장식 도형도 지워야** 빈 아이콘이 남지 않는다.
2. **placeholder 크기를 바꾸면 레이아웃도 같이 바꾼다.** PowerPoint는 슬라이드의 `xfrm`을 우선하지만 **LibreOffice 렌더는 레이아웃 지오메트리를 그린다.** 슬라이드에서만 카드 높이를 줄이면 PDF 미리보기에 옛 크기 카드가 그대로 보여 검수가 어긋난다 → 레이아웃의 같은 placeholder도 동일 값으로 동기화할 것. (레이아웃을 다른 슬라이드가 쓰지 않는지 먼저 확인)
3. **콘텐츠 우측 한계는 x ≈ 10,540,000 EMU.** 헤어라인은 11,679,367까지 가지만 템플릿의 모든 본문 블록은 10.54M에서 끝난다 — 우하단 데코 자리를 비워두는 설계다. 카드를 헤어라인 끝까지 늘리지 말 것.
4. **템플릿 카드는 대부분 내용보다 크다.** 3~4줄만 넣으면 텍스트가 카드 안에서 떠 보인다. 카드 높이를 내용에 맞춰 줄이고 블록 전체를 세로 중앙(콘텐츠 영역 중심 ≈ y 3,900,000)에 맞춘다.

## 8. 제작 워크플로

```
1) claude/assets/ppt_16_9_light.pptx 를 작업 폴더로 복사
2) §7에서 필요한 유형의 슬라이드 번호를 고른다
3) 해당 슬라이드를 복제 → 텍스트만 교체 (도형·좌표·색은 건드리지 않음)
4) 불필요한 템플릿 슬라이드(2–8 가이드 포함) 삭제
5) 폰트 교체(§3) → soffice --headless --convert-to pdf 로 렌더 → pdftoppm 으로 PNG 확인 (필수 검수)
   렌더 전 Pretendard 설치 확인: fc-list | grep Pretendard
6) 팔레트/폰트/좌표가 이 문서와 어긋나지 않는지 대조
```

렌더 검수 명령:
```bash
soffice --headless --convert-to pdf deck.pptx --outdir .
# 검수는 PDF를 직접 열어서 본다. PNG/JPG 이미지 파일은 만들지 않는다.
```
> **[사용자 지시]** 산출물은 **pptx만** 전달한다. 슬라이드 미리보기 이미지(jpg/png)는 생성하지도, 전달하지도 않는다. 시각 검수는 PDF로 하고 검수 후 PDF도 삭제한다.
