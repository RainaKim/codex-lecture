  • 이어지는 곳: 18강 — GitHub Issue에서 시작: 역할 프롬프트와 승인 지점이 이어서 쓰는 입력

연출 메모

「역할 분리」 카드를 가리키며 — Chapter 4의 나머지 강의는 이 역할들이 Issue에서 PR 설명까지 이어서 일하는 흐름이라고 말한다. 칩 셋은 모두 다음 강의의 입력이 된다 — 역할 프롬프트는 그대로 쓰고, 승인 지점은 Issue 템플릿의 결정 항목으로 들어간다. 18강 예고는 검은 카드 한 줄로 닫는다.
